# 🕵️ AI Data Detective

### Automated Dataset Intelligence System

AI Data Detective is a Python-powered data intelligence tool that analyzes CSV datasets and generates useful insights through automated profiling, data-quality analysis, statistics, correlation analysis, visualization, machine learning, and report generation.

---

## 🚀 Features

- 📂 Load built-in or custom CSV datasets
- 🔎 Automated dataset profiling
- 📊 Statistical analysis
- 🧹 Data-quality analysis
- ⚠️ Missing-value detection
- 🔁 Duplicate detection
- 📈 Outlier detection
- 🔗 Correlation analysis
- 🤖 Machine-learning classification
- 📐 Machine-learning regression
- 🏆 Model comparison
- 📉 Automatic visualization generation
- 📄 Automated report generation
- 🖥️ Interactive terminal interface
- 💻 Local Python processing

---

## 🧠 Machine Learning Models

### Classification

- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting

### Regression

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- Gradient Boosting Regressor

All model results are calculated using real Scikit-learn models.
